# Python Number Guessing Game 🎯

About

A simple number guessing game built using Python. The computer randomly selects a number between 1 and 50, and the player tries to guess the correct number.

Features

- Computer randomly selects a number between 1 and 50.
- Unlimited attempts to guess the number.
- Rejects guesses outside the range of 1–50.
- Displays "Don't you know what comes in from 1 to 50. Are you dumb?" when the player enters a number outside the allowed range.
- Allows the player to play again after finishing a game.
- Includes a Python source file and a Windows executable (".exe").

Technologies Used

- Python

How to Run

Option 1: Run Using Python

1. Download or clone this repository.
2. Make sure Python is installed on your computer.
3. Open a terminal or command prompt in the project folder.
4. Run the following command:

python number-guessing-game.py

Option 2: Run Using the Windows Executable

1. Download "number-guessing-game.exe" from this repository.
2. Open the file on a Windows computer.
3. Follow the instructions displayed by the game.

Note: The executable is intended for Windows. Only run downloaded executable files from sources you trust.

Purpose

This project was created to practice Python programming, random number generation, user input, and basic game logic.
